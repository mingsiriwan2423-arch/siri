ขั้นตอนการนำไฟล์ขึ้น GitHub Pages (สำหรับนักศึกษา)

ไฟล์นี้เป็นแบบ Single-file HTML (รวม HTML + Tailwind CSS + JavaScript ในไฟล์เดียว) ออกแบบมาให้รองรับการเปิดใช้งานบน GitHub Pages ฟรีทันที
  1. สร้าง Repository ใหม่:

    เข้าไปที่ GitHub.com -> เลือก Create a new repository ตั้งชื่อ เช่น covid19-public-health-dashboard แล้วเลือก Public

  2. อัปโหลดไฟล์ HTML:

    คัดลอก/บันทึกไฟล์โค้ดนี้ทั้งหมดลงเครื่อง ตั้งชื่อไฟล์เป็น index.html แล้วอัปโหลดขึ้น Repository บน GitHub

  3. เปิดใช้งาน GitHub Pages:

    ไปที่เมนู Settings ของ Repository -> ด้านซ้ายเลือก Pages

  4. เลือก Branch สำหรับ Deployment:

    ส่วน Build and deployment ให้เลือก Branch เป็น main (โฟลเดอร์ /root) จากนั้นคลิก Save

  5. เสร็จสมบูรณ์:

    รอประมาณ 1-2 นาที ระบบจะสร้าง URL สำหรับเปิด Dashboard ออนไลน์ให้ เช่น https://your-username.github.io/covid19-public-health-dashboard/
